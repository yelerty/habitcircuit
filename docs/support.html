자주 묻는 질문 (FAQ)

Q. 루틴은 어떻게 추가하나요?

우측 상단의 ✏️ (편집) 아이콘을 클릭하거나, 루틴이 있는 경우 루틴을 0.5초 동안 꾹 누르면 편집 화면으로 이동합니다. 편집 화면에서 새로운 루틴을 추가할 수 있습니다.

Q. 루틴의 아이콘을 변경하려면?

편집 화면에서 루틴 옆의 연필 아이콘을 클릭하면 카테고리 아이콘 선택기가 나타납니다. 9가지 카테고리 중 원하는 아이콘을 선택할 수 있습니다.

Q. 알림은 어떻게 설정하나요?

설정 화면에서 아침·점심·저녁 각 시간대별로 알림 시간을 설정할 수 있습니다. 알림을 활성화하면 설정한 시간에 루틴 알림을 받을 수 있습니다.

Q. 루틴을 다른 사람과 공유하려면?

설정 > "웹에서 공유하기"를 클릭하면 루틴 공유 웹페이지가 열립니다. 거기서 루틴을 선택하고 공유하면 QR 코드가 생성됩니다.

Q. 다른 사람의 루틴을 가져오려면?

두 가지 방법이 있습니다:
1) 웹에서 공유된 루틴을 선택하고 "📤 공유하기" 버튼을 눌러 "HabitCircuit에 추가" 선택
2) 설정 > "루틴 가져오기"에서 JSON 파일 선택

Q. 루틴 실행 시간이 제한되나요?

네. 각 루틴은 알림 시간 기준으로 1시간 전부터 3시간 후까지 실행할 수 있습니다. 예를 들어 아침 알림이 7시라면, 6시부터 10시까지 아침 루틴을 실행할 수 있습니다.

Q. 루틴을 저장해두고 나중에 불러올 수 있나요?

네! 설정 > "저장된 루틴 관리"에서 최대 5개의 루틴 세트를 저장하고 불러올 수 있습니다. 평일용, 주말용 등 상황별로 관리할 수 있습니다.

Q. 모든 루틴을 한번에 삭제하려면?

설정 > "저장된 루틴 관리" > "현재 루틴 모두 삭제" 버튼을 클릭하면 모든 루틴을 삭제할 수 있습니다.

Q. 연속 달성일이 리셋되었어요!

연속 달성일은 매일 모든 루틴을 완료해야 유지됩니다. 하루라도 완료하지 못하면 리셋되지만, 최장 기록은 보관됩니다.

Q. 데이터는 어디에 저장되나요?

모든 데이터는 iPhone/iPad의 로컬 저장소에 안전하게 보관됩니다. 서버로 전송되지 않으며, iCloud 백업에는 포함될 수 있습니다.

주요 기능 안내

🎯 루틴 추가 및 편집

  1. 우측 상단 ✏️ 아이콘 클릭
  2. 시간대(아침/점심/저녁) 선택
  3. 카테고리 아이콘 선택
  4. 루틴 이름 입력 후 추가
  5. 드래그로 순서 변경 가능

🔥 루틴 실행

  1. 홈 화면에서 "루틴 시작" 버튼 클릭
  2. 현재 루틴을 하나씩 완료
  3. 체크 버튼으로 완료 표시
  4. 모든 루틴 완료 시 축하 화면

💾 루틴 백업 및 복원

  1. 설정 > "루틴 내보내기"로 JSON 파일 저장
  2. 설정 > "루틴 가져오기"로 복원
  3. 여러 기기 간 루틴 동기화 가능

문제 해결

알림이 오지 않아요

1. iPhone 설정 > 알림 > 습관 써클에서 알림 권한 확인
2. 앱 내 설정에서 각 시간대 알림이 활성화되어 있는지 확인
3. 방해금지 모드가 켜져있는지 확인

루틴이 사라졌어요

1. 올바른 요일과 시간대가 선택되어 있는지 확인
2. 실수로 삭제하지 않았는지 확인
3. 백업 파일이 있다면 "루틴 가져오기"로 복원

앱이 느리거나 멈춰요

1. 앱을 완전히 종료 후 재시작
2. iPhone/iPad 재부팅
3. 최신 버전으로 업데이트
4. 문제가 계속되면 아래 연락처로 문의
