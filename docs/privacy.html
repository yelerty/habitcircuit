개인정보 처리방침

습관 써클 (HabitCircuit)

최종 수정일: 2025년 1월 9일

간단 요약

습관 써클은 여러분의 개인정보를 소중히 여깁니다. 모든 데이터는 기기 내에 안전하게 저장되며, 서버로 전송되지 않습니다. 선택적으로 루틴을 공유할 수 있지만, 개인을 식별할 수 있는 정보는 포함되지 않습니다.

1. 개인정보의 수집 및 이용 목적

습관 써클("본 앱")은 다음의 목적을 위해 최소한의 정보만을 처리합니다:

  • 루틴 데이터 저장 및 관리
  • 연속 달성 기록 추적
  • 알림 서비스 제공
  • 앱 사용성 개선

2. 수집하는 정보

2.1 로컬 저장 정보 (기기 내부에만 저장)

  • 루틴 데이터: 사용자가 생성한 루틴의 이름, 카테고리, 시간대, 순서
  • 완료 기록: 루틴 완료 여부 및 완료 날짜
  • 연속 달성 데이터: 현재 연속일, 최장 기록, 총 완료 일수
  • 설정 정보: 알림 시간, 활성화 상태
  • 저장된 루틴 세트: 사용자가 저장한 최대 5개의 루틴 세트

중요: 위 정보는 모두 사용자의 기기(iPhone/iPad)에만 저장되며, 외부 서버로 전송되지 않습니다.

2.2 선택적 공유 정보

  • 루틴 공유 시: 사용자가 명시적으로 공유를 선택한 루틴 데이터만 Firebase에 임시 저장됩니다
  • 공유된 정보에는 개인 식별 정보가 포함되지 않습니다
  • 루틴 이름, 카테고리, 시간대만 포함됩니다

2.3 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 위치 정보
  • 연락처
  • 사진 및 미디어
  • 기기 고유 식별자(선택적 광고 ID 제외)

3. 정보의 저장 및 보관

3.1 로컬 저장

모든 루틴 데이터는 iOS Core Data를 사용하여 기기 내부에 암호화되어 저장됩니다.

3.2 iCloud 백업

iOS 시스템 설정에 따라 앱 데이터가 iCloud에 백업될 수 있습니다. 이는 Apple의 개인정보 처리방침을 따릅니다.

3.3 공유 데이터

사용자가 선택적으로 공유한 루틴 데이터는 Firebase Firestore에 저장되며:

  • 공유 후 30일간 보관 후 자동 삭제됩니다
  • 사용자가 언제든지 삭제 요청할 수 있습니다
  • 개인 식별 정보는 포함되지 않습니다

4. 정보의 제3자 제공

본 앱은 사용자의 개인정보를 제3자에게 제공하지 않습니다. 단, 다음의 경우 예외가 적용됩니다:

  • 법령에 의해 요구되는 경우
  • 사용자의 명시적 동의가 있는 경우

5. 제3자 서비스

5.1 Google AdMob (광고)

본 앱은 Google AdMob을 사용하여 광고를 표시합니다:

  • AdMob은 광고 게재를 위해 광고 ID를 사용할 수 있습니다
  • 사용자는 iOS 설정에서 "광고 추적 제한"을 활성화할 수 있습니다
  • AdMob 개인정보 처리방침: https://policies.google.com/privacy

5.2 Firebase (루틴 공유)

루틴 공유 기능은 Google Firebase를 사용합니다:

  • 사용자가 명시적으로 공유를 선택한 경우에만 데이터가 전송됩니다
  • Firebase 개인정보 처리방침: https://firebase.google.com/support/privacy

6. 사용자의 권리

사용자는 다음의 권리를 가집니다:

6.1 열람권

앱 내에서 언제든지 저장된 모든 데이터를 확인할 수 있습니다.

6.2 정정권

앱 내에서 루틴 데이터를 직접 수정할 수 있습니다.

6.3 삭제권

  • 개별 루틴 삭제
  • 전체 루틴 삭제 (설정 > 저장된 루틴 관리 > 현재 루틴 모두 삭제)
  • 앱 삭제 시 모든 데이터가 영구 삭제됩니다

6.4 데이터 이동권

설정 > "루틴 내보내기"를 통해 JSON 형식으로 데이터를 내보낼 수 있습니다.

7. 보안

본 앱은 다음과 같은 보안 조치를 취하고 있습니다:

  • iOS Core Data의 기본 암호화 사용
  • 데이터는 기기 내부에만 저장 (로컬 저장)
  • HTTPS를 통한 안전한 통신 (공유 기능 사용 시)
  • 정기적인 보안 업데이트

8. 아동의 개인정보 보호

본 앱은 만 14세 미만 아동으로부터 의도적으로 개인정보를 수집하지 않습니다. 만약 부모님께서 자녀가 본 앱을 통해 개인정보를 제공했다고 판단되시면 즉시 연락주시기 바랍니다.

9. 개인정보 처리방침의 변경

본 개인정보 처리방침은 법령 또는 서비스의 변경사항을 반영하기 위해 수정될 수 있습니다. 중요한 변경사항이 있을 경우 앱 내 공지사항을 통해 알려드립니다.

10. 데이터 보관 기간

데이터 유형 보관 위치 보관 기간
루틴 데이터 기기 내부 사용자가 삭제하거나 앱을 제거할 때까지
연속 달성 기록 기기 내부 사용자가 삭제하거나 앱을 제거할 때까지
설정 정보 기기 내부 사용자가 변경하거나 앱을 제거할 때까지
공유된 루틴 Firebase 공유 후 30일 (자동 삭제)

11. 국제 데이터 전송

본 앱의 데이터는 기본적으로 사용자의 기기에만 저장됩니다. 루틴 공유 기능 사용 시, 데이터가 Google Firebase 서버(미국 또는 기타 국가)에 저장될 수 있습니다. Google은 적절한 보안 조치를 취하고 있습니다.
